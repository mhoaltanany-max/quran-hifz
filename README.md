# رفيق الحفظ

تطبيق لاسترجاع حفظ القرآن الكريم صفحةً صفحة، يعمل بدون إنترنت ويُثبَّت على الجوال كتطبيق.

- المصحف كاملًا بالرسم العثماني، رواية حفص عن عاصم، مقسّمًا على صفحات مصحف المدينة (604 صفحة).
- ثلاث خطوات لكل صفحة: قراءة، ثم تلميح بأوائل الكلمات، ثم اختبار كلمةً كلمة مع تعليم الأخطاء.
- مراجعة متباعدة: بعد كل اختبار تقيّم حفظك، فيحدد التطبيق موعد مراجعة الصفحة.
- الاستماع للتلاوة اختياري ويحتاج إنترنت.

## التثبيت على الجوال

افتح رابط التطبيق مرة واحدة وأنت متصل بالإنترنت، ثم:

- **أندرويد (Chrome):** اضغط «تثبيت» في الشريط الذي يظهر، أو من القائمة ⋮ اختر «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».

بعدها يعمل التطبيق من أيقونته بدون إنترنت.
