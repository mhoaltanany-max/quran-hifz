# رفيق الحفظ

تطبيق لاسترجاع حفظ القرآن الكريم صفحةً صفحة، يعمل بدون إنترنت ويُثبَّت على الجوال كتطبيق.

- المصحف كاملًا بالرسم العثماني، رواية حفص عن عاصم، مقسّمًا على صفحات مصحف المدينة (604 صفحة).
- ثلاث خطوات لكل صفحة: قراءة، ثم تلميح بأوائل الكلمات، ثم اختبار كلمةً كلمة مع تعليم الأخطاء.
- مراجعة متباعدة: بعد كل اختبار تقيّم حفظك، فيحدد التطبيق موعد مراجعة الصفحة.
- **التفسير:** اضغط أي آية لترى تفسيرها من التفسير الميسّر، واضغط اسم السورة لترى سبب تسميتها ومقاصدها.
- **أسباب النزول:** من كتاب الواحدي، والآيات التي لها سبب نزول عليها نقطة حمراء.
- **البحث:** في نص القرآن كله، بالتشكيل أو بدونه.
- الاستماع للتلاوة اختياري ويحتاج إنترنت.

## تحميل تطبيق أندرويد

[تحميل rafiq-alhifz.apk](https://github.com/mhoaltanany-max/quran-hifz/releases/latest/download/rafiq-alhifz.apk)

## التثبيت من المتصفح

افتح رابط التطبيق مرة واحدة وأنت متصل بالإنترنت، ثم:

- **أندرويد (Chrome):** اضغط «تثبيت» في الشريط الذي يظهر، أو من القائمة ⋮ اختر «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».

بعدها يعمل التطبيق من أيقونته بدون إنترنت.

## المصادر

- النص القرآني: [مشروع تنزيل](https://tanzil.net) (Tanzil Quran Text، الرسم العثماني)، منقول دون تعديل، عبر [quran-json](https://github.com/risan/quran-json).
- التفسير الميسّر: مجمع الملك فهد لطباعة المصحف الشريف، عبر [tafsir_api](https://github.com/spa5k/tafsir_api) (MIT).
- أسباب النزول للواحدي: [الموسوعة القرآنية quranpedia.net](https://quranpedia.net)، نسخة البيانات 2026-08-10 (الملفات الأصلية في `data-raw/quranpedia`).
- خط المصحف: Scheherazade New من SIL، برخصة SIL Open Font License 1.1.
- التلاوات: cdn.islamic.network.

## البناء

- `tools/prepare_data.py` يجهّز ملفات `data/` من المصادر.
- `tools/build.py` يجمع `src/app.html` مع البيانات في `index.html`.
- عند كل دفع إلى `main` يبني GitHub Actions ملف APK وينشره في Releases.
